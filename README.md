# Neurova Focus Lab 🌿

An AI-powered student focus and concentration platform.

Neurova Focus Lab analyses focus patterns, study habits, sleep, and daily routines to provide personalised insights and practical strategies for improving concentration.

**Features**
- AI-based concentration predictions
- Personal focus experiments and progress reports
- Personalised study-strategy suggestions
- Healthy study-habit guidance

*Built as a Class 12 AI capstone project.*
